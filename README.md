## 🎯 DarkHeida Nedir?

DarkHeida, dizüstü bilgisayarınızın **gücünü tek panelden** yönetmenizi sağlayan bir araçtır.

- ⚡ **Performans modları** — Windows, Sessiz, Performans, Turbo
- 🖥️ **Ekran ayarları** — Parlaklık, yenileme hızı
- 🔋 **Pil yönetimi** — Durum, şarj limiti, otomatik tasarruf
- ⌨️ **Klavye** (geliştiriciler ekleyecek)
- 🛠️ **Gelişmiş sayfa** — Geliştiriciler kendi özelliklerini ekleyebilir

**Açık kaynak. Ücretsiz. Reklamsız.**

---

## ✨ Özellikler

### 🎨 Arayüz
- **6 sayfa** — Performans, Ekran, Pil, Gelişmiş, Klavye, Ayarlar
- **10 hazır tema** + özel tema oluşturma
- **20 dil desteği**
- **Shimmer animasyonları**, modern kartlar

### ⚡ Performans
- **Canlı istatistik** — CPU, RAM, Disk, Ağ
- **4 güç modu** — Gerçek Windows güç planı değiştirme
- **Ağ sayacı** — Kalıcı (kapat-aç devam eder)
- **Çalışma süresi**

### 🖥️ Ekran
- **Parlaklık kontrolü**
- **Yenileme hızı** — 60Hz / 144Hz
- **Çözünürlük** ve **mevcut Hz**

### 🔋 Pil
- **Pil yüzdesi** ve **durum**
- **Otomatik tasarruf** — %20 altına inince

### 🆘 Tepsi Desteği
- **Sistem tepsisinde ikon** (G Helper gibi)
- **Hızlı mod** değiştirme (tepsiden)
- **Başlangıçta çalıştır** toggle
- **Destek menüsü** (Destek sayfası + Hata bildir)
- **Yeniden başlat** (tepsiden)
- **Çıkış** (tepsiden)

### 🌐 Diğer
- **Başlangıçta çalıştır**
- **Config kalıcılığı**
- **Modern Tasarım**
- **Kullanımı Rahat Özel Tasarım imkanı**
